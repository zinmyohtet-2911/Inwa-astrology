# Inwa Astrology

A web application designed to calculate and display traditional Burmese astrological data and planetary characteristics.

🚀 **Live Demo:** [https://inwa-astrology.vercel.app](https://inwa-astrology.vercel.app)

---

## 🌟 Features
- Display detailed planetary characteristics and astrology insights
- Clean and user-friendly interface
- Fully responsive design for mobile and desktop screens

## 🛠️ Tech Stack
- **Language:** JavaScript (ES6+)
- **Markup & Styling:** HTML5, CSS3 / Tailwind CSS
- **Deployment:** Vercel
- **Version Control:** Git & GitHub
